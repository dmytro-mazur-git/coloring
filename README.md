# Сани Санти і Рудольф

Інтерактивна розмальовка в браузері: Санта на санях з мішком подарунків і четверо оленів, попереду Рудольф з червоним носом.

Відкрийте `index.html` у браузері, оберіть олівець і натискайте на частини малюнка. Є кнопки «Назад», «Показати приклад» і «Очистити все». Малюнок зберігається в `localStorage`.
