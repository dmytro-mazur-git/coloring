# Difficulty profiles

Pixel values are for the printable area at 300 DPI (about 2244 × 3272 px on A4 with 10 mm margins).

| Profile | Age | Line width | Closed regions | Content |
|---------|-----|------------|----------------|---------|
| `easy`   | 3–5  | 8–14 px | ≤ 40     | one large subject, no background, very simple shapes |
| `medium` | 6–8  | 5–8 px  | 30–150   | subject + simple background |
| `hard`   | 9–12 | 3–5 px  | 100–400  | detailed scene, patterns |

The numeric values live in `config.yaml` (`profiles`). This table is the human-readable summary.
